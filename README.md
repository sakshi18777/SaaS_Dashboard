📊 SaaS Pulse - Customer Retention & Revenue Intelligence

📌 Project Overview
SAAS PULSE is an interactive Power BI dashboard designed to analyze SaaS business performance, monitor customer retention, track recurring revenue, and identify customer churn patterns.

 🎯 Key Performance Indicators
- Total Customers: 500
- Active MRR:₹10M
- Churned Customers: 110
- Customer Churn Rate: 22%
- Trial Accounts: 97
- Paid Accounts: 318

📈 Dashboard Insights
The dashboard provides insights into:
- Monthly Recurring Revenue (MRR) by subscription plan
- Churned customers by subscription plan
- Support ticket volume by priority
- Churned accounts by signup year
- Customer distribution by industry
- Most-used product features
- Top reasons for customer churn
- Churn events by year

🛠️ Tools & Technologies
- Power BI — Dashboard development and data visualization
- Data Analytics — KPI monitoring and business performance analysis

 🎛️ Interactive Features
- Subscription plan filtering
- Country filtering
- KPI cards and interactive charts
- Customer retention and churn analysis

 💡 Business Value
This dashboard helps stakeholders monitor SaaS performance, understand customer churn, evaluate subscription trends, and identify areas for improving customer retention.
